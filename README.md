# Borrowed Shapes

A Unity-based multiplayer game with an accompanying web platform.

## About This Repository

This repository is an archived copy of the project, migrated from Unity Version Control (formerly Plastic SCM) for portfolio and reference purposes. The original commit history and active development remain on Unity VCS — this GitHub repo reflects a single snapshot of the project at the time of migration.

## Tech Stack

- **Game:** Unity, C#
- **Backend:** NestJS
- **Frontend:** Next.js
- **Database:** PostgreSQL, Redis
- **Infrastructure:** Docker, Cloudflare R2
